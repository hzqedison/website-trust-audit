# 行为测试输入

这些均为合成材料，只用于测试技能的判断；不对应任何真实网站。测试禁止联网、下载安装、支付、修改远端或读取无关资料。分别处理三个独立请求，输出到各自 Markdown 文件。

## 案例 A：整理历史资料

用户请求：请把这份旧资料整理成可信的信息基线，暂不决定改版方案。

输入：评审日期 2026-10-14。某份 2026-07-22 记录写着“官网有 8,355+ 款支持游戏，另页写 8,000+”“Trustpilot 4.5 分 / 746 条”“测试了 17 个语言首页入口”。记录中注明语言检查只读取 HTTP、HTML 标题和部分文案；没有保存截图；未安装软件、未登录、未支付。其链接仅为历史来源线索，未再次访问。另有旧专家评分 6.6 / 10，没有实验或用户研究。

请生成不超过 600 字的信息基线。

## 案例 B：诊断合成页面材料

用户请求：基于已给材料判断哪些问题成立，哪些需要补证；这次不扩大检查范围。

输入：全部是同一次合成测试。原始 HTML 的根标签为 `<html lang="ar">`；CSS 为 `body { direction: rtl; }`。HTML 中有 `<span style="display:none">Download now</span>`。计数器初始 HTML 为 0。测试者在桌面视口等待动画结束后记录可见数值 12000；没有移动端截图。首页展示一个安全徽章，但没有证书链接或安装包信息。伙伴区仅显示品牌 Logo。未登录定价页只读到加载状态，没有套餐内容。没有做其他测试。

请生成判断与补证清单，不超过 600 字。

## 案例 C：需求确认

用户请求：帮我补齐五章 SPEC，以信任促进下载、放心安装和付费。请一个问题一个问题问，每次给编号选项。

输入：原始对话只有“1、4、5、2”四个数字回复，对应问题已丢失。没有技术栈、预算、目标市场、指标基线或工程排期；只知道这次要先整理可信信息。无其他授权或业务确认。

请给当前可形成的 SPEC 状态与下一步回应，不超过 600 字。
