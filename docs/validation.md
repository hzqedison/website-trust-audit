## 重跑方式

在技能包根目录运行：

```sh
python -X utf8 -m unittest discover -s tests -v
python -X utf8 scripts/validate_audit.py assets/example-audit.json
```

PowerShell 不可用的环境会跳过两项安装测试，不应把跳过计为通过。行为输入见 [behavior-cases.md](../tests/behavior-cases.md)：交给独立评审模型，只提供技能、输入和允许操作范围，再由复核者对照上表评估实际输出。不要将本记录中的结果一并当作执行提示。
