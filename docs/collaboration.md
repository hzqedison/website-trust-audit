# 团队协作约定

- 采集人提交范围、原始证据、方法、时间、上下文和附件；不把结论包装成观察。
- 复核者独立核对事实、来源与推断边界，指出缺证和不可比条件。
- 业务负责人确认需求、方案和五章 SPEC；不根据审计人的推测自动批准改版。
- 不编造人员姓名或职责归属。未知 owner 标记待指定。
- PR 对证据记录逐项标明新增、变更、撤回或未复核，并写明原因；保留旧记录和历史状态，不覆盖历史。
- 数据、截图和报告留在对应项目目录。通用 skill 只维护可复用的方法、schema、模板和工具，不纳入客户私有数据或本机绝对路径。
- Planner/reviewer 模型可配置为当前选择的模型，executor 可配置为低成本模型；技能文本本身不保证模型路由。只有宿主支持且用户授权代理时才实际委派。
